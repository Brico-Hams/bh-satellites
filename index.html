Interfaz CAT por puerto serie

Kenwood ASCII y CAT SAT RX Quansheng F4HWN · sin PTT

Desconectado
Firmware F4HWN v6+ compatible, modo SAT RX y CAT habilitado con tecla 8. Solo recepción, bandas 136–174 y 400–470 MHz. 38400 baudios. No transmite ni escribe memoria o firmware.
Web Serial depende del navegador y de los permisos del sistema. El protocolo implementado es Kenwood ASCII compatible (FA/FB/MD). Comprueba tu modelo antes de enviar comandos; la lectura o sintonía puede variar según equipo.

La sintonización automática requiere equipo conectado, confirmación expresa, satélite sobre el horizonte y datos orbitales recientes. No envía comandos de transmisión/PTT.

Comandos y control seguro

Comandos compatibles implementados: FA###########; VFO A, FB###########; VFO B, MD; consulta. No hay transmisión, PTT ni comandos de potencia.

En modo una radio, se escribe VFO A para recibir y VFO B para transmitir. El software no activa el split ni garantiza la asignación de banda de tu equipo: configúralo y compruébalo antes de transmitir.

Para Android, Web Serial puede no estar disponible. La interfaz gráfica y los cálculos sí siguen funcionando offline.

Entrada de sonido y grabación

Web Audio · sin envío de audio a servidores

Audio detenido
La entrada procede de la salida de audio demodulada del receptor (FM/SSB). Se desactivan cancelación de eco, control automático de ganancia y reducción de ruido cuando es posible.
Nivel de entrada
Esperando permiso de micrófono.

Al grabar, los datos PCM se mantienen en memoria hasta descargar el WAV; para grabaciones largas, vigila la memoria disponible.

Decodificación SSTV

Martin M1 · receptor experimental

Inactivo
Experimental: solo interpreta Martin M1 (320×256) con sincronización por línea aproximada; no detecta VIS ni garantiza la reconstrucción ante ruido o deriva. Es un primer decodificador, no una implementación completa de SSTV.

Inicia la recepción, activa SSTV y espera una transmisión Martin M1.

Datos orbitales

Importación manual, o actualización opcional con conexión

—
El cálculo local usa Kepler con perturbación secular J2, NO SGP4. Los TLE son elementos medios SGP4; aquí las posiciones y pasadas son aproximadas y no deben usarse como referencia para apuntado o CAT automático de precisión. Renovar los elementos no sustituye un propagador SGP4 validado.

La descarga necesita internet y acceso CORS; el seguimiento y el catálogo guardado funcionan offline. El catálogo amplio usa CelesTrak activos y varios grupos complementarios. Algunos navegadores bloquean descargas desde file://: en ese caso importa el archivo TLE descargado por separado.

Ejemplos integrados.
Se admiten conjuntos de dos o tres líneas TLE y registros OMM JSON de CelesTrak. Para nuevas catalogaciones con identificadores de seis dígitos, usa OMM JSON.

Configuración portable

Los favoritos, grupos, coordenadas, transpondedores y elementos orbitales se intentan almacenar en el navegador mediante localStorage. También puedes exportarlos y restaurarlos sin internet.

Arquitectura y limitaciones

100 % incrustado: mapa vectorial, cálculo orbital J2, lista inicial, transpondedores, Doppler, interfaz CAT y decodificación SSTV experimental. No se descargan scripts, fuentes ni recursos para arrancar.
Hardware: CAT Web Serial solo en navegadores compatibles y con permisos, audio solo con acceso al micrófono. En Android probablemente hará falta una capa nativa para CAT.
Con precisión profesional: sustituir el propagador J2 por SGP4/SDP4 validado, ampliar perfiles CAT, instrumentar pruebas de integración y completar protocolos SSTV.
BH-SATELITES · Herramienta experimental para radioaficionados. El cálculo y la configuración se realizan en el dispositivo. Verifica licencias, bandas, equipo, estado y frecuencias antes de operar. Fuentes de las plantillas: AMSAT, SatNOGS y elementos orbitales públicos.
